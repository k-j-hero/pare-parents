# 근거 자료 수집 및 검토 기준

## 목적

Pare의 권위는 자료의 양이 아니라 각 안내가 어떤 근거에서 어떻게 만들어졌는지 추적하고 검증할 수 있는 데서 나온다. 이 문서는 자료 발견부터 가이드 공개와 재검토까지의 기준을 정한다.

## 자료의 역할

| 자료 유형 | 용도 | 근거로서의 취급 |
|---|---|---|
| 공공기관·전문학회 지침 | 우선 행동과 안전 기준 | 적용 지역, 버전과 개발 방법을 평가 |
| 체계적 문헌고찰·메타분석 | 전체 효과와 불확실성 파악 | 검색 범위, 편향과 최신성을 평가 |
| 개별 동료평가 연구 | 세부 질문과 신규 근거 보완 | 단독으로 강한 권고를 만들지 않음 |
| 전문 서적 | 이론과 실천 맥락 보완 | 서지정보와 검토자가 작성한 요약 중심 |
| 커뮤니티 | 실제 사용자 문제와 표현 발견 | 사실이나 행동 지침의 근거로 사용하지 않음 |

## 수집 원칙

- 공식 API, 공개 데이터 덤프 또는 명시적으로 허용된 수집 경로를 우선한다.
- robots 정책, 이용약관, 저작권, 데이터베이스권과 개인정보 조건을 출처별로 확인한다.
- 논문·책의 메타데이터 이용 가능성과 원문 복제 가능성을 구분한다.
- 원문 저장은 문서별 라이선스와 상업적 이용 가능 범위를 확인한 경우에만 허용한다.
- 라이선스가 불명확하거나 저장이 금지된 자료는 식별자, 서지정보와 외부 링크만 보관한다.
- 커뮤니티 자료는 허가 또는 공식 API 없이 대량 수집하지 않는다.
- 커뮤니티 작성자, 아이 이름, 건강정보와 재식별 가능한 문장을 근거 저장소에 복제하지 않는다.
- 수집 요청은 제공자의 속도 제한을 준수하고 캐시, 재시도 제한과 지수 백오프를 사용한다.

법률과 이용약관 해석이 필요한 출처는 수집 전에 전문가 검토 대상으로 표시한다.

## 데이터 계층

### Source

- 자료 유형, 제목, 저자와 발행기관
- DOI, PMID, ISBN 또는 공식 식별자
- 발행일, 버전과 원문 URL
- 라이선스, 허용 범위와 확인 근거
- 수집일, 마지막 확인일과 내용 해시
- 철회, 정정, 대체와 만료 상태

### Evidence Claim

- 대상 연령과 모집단
- 상황 또는 질문
- 개입·행동과 비교 조건
- 측정 결과, 효과와 잠재적 위해
- 연구 설계와 직접 확인 위치
- 연구 결과와 검토자의 해석 구분

### Evidence Assessment

- 편향 위험
- 직접성, 일관성, 정밀성과 출판 편향
- 근거 확실성
- 국내 환경 및 대상 연령 적용 가능성
- 평가자, 평가일과 평가 방법

### Guide

- 지금 할 행동, 피해야 할 행동과 대화 예시
- 상황이 진정된 뒤의 행동
- 전문가 도움이 필요한 신호
- 연결된 근거 주장과 출처
- 적용 연령, 검토자, 검토일과 재검토 기한
- 공개 버전과 변경 이력

## 근거 등급

초기 표시 체계는 다음과 같이 운영하되, 공개 전 방법론 전문가와 용어 및 판정 기준을 검토한다.

- A: 신뢰할 만한 최신 지침 또는 높은 확실성의 종합 근거
- B: 중간 수준의 종합 근거
- C: 제한적이거나 간접적인 연구 근거
- D: 전문가 합의 또는 실무적 제안
- 미평가: 검토가 끝나지 않아 공개 불가

근거 등급과 권고 강도는 동일하지 않다. 이익과 위해, 사용자 가치, 실행 가능성과 적용 맥락도 별도로 기록한다.

## 승인 워크플로

```text
discovered -> imported -> screened -> assessed
-> drafted -> in_review -> approved -> published -> archived
```

- 자동 수집 결과는 `imported` 이상으로 자동 승격하지 않는다.
- 근거 평가는 평가자와 방법을 기록해야 한다.
- 작성자와 최종 검토자를 가능한 범위에서 분리한다.
- 응급·의료·발달 관련 안전 문구는 적격 전문가 승인 없이는 공개하지 않는다.
- 공개 콘텐츠는 특정 승인 버전을 참조하며 수정 시 새 버전을 만든다.
- 검토 기한 경과, 핵심 출처 철회·정정 또는 상위 지침 변경 시 재검토 대상으로 전환한다.

## AI 사용 기준

AI는 자료 후보 분류, 중복 탐지, 구조화 초안과 쉬운 문장 초안을 보조할 수 있다. 다음 판단을 자동 확정할 수 없다.

- 근거 확실성과 권고 강도
- 인과관계와 연령 적용성
- 위해와 응급 위험
- 최종 사용자용 행동 지침
- 공개 승인

AI가 만든 필드는 생성 모델, 프롬프트 버전, 생성 시점과 검토 상태를 기록하고 사람의 승인 전에는 사용자 답변에 포함하지 않는다.

## 품질 관리

- 중복 식별 정확도와 잘못 합쳐진 자료를 표본 검사한다.
- 원문과 구조화 필드의 일치 여부를 검사한다.
- 출처 링크, 라이선스와 철회 상태를 정기적으로 재확인한다.
- 가이드의 모든 핵심 행동 문장이 하나 이상의 승인된 근거 또는 명시된 전문가 합의와 연결되는지 검사한다.
- 근거가 충돌하면 불확실성을 숨기지 않고 공개 표현과 제한 조건에 반영한다.

## 출처별 등록 체크리스트

- [ ] 공식 식별자와 원본 URL을 확인했다.
- [ ] API·크롤링·저장·상업적 이용 조건을 확인했다.
- [ ] 원문 저장 가능 여부와 라이선스를 기록했다.
- [ ] 개인정보와 민감정보 포함 가능성을 확인했다.
- [ ] 정정·철회·버전 갱신을 확인할 방법이 있다.
- [ ] 재수집 주기와 실패 시 처리 방법이 있다.
- [ ] 공개 답변에 사용할 수 있는 범위를 명시했다.
