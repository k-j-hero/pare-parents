# 제품 정의

이 문서는 제품의 목표와 범위를 고정하는 기준 문서다. 구현 전에 미정 항목을 사용자와 확정한다.

## 제품 개요

- 제품명(가칭): Pare
- 한 문장 정의: 부모가 아이의 감정과 행동을 이해하고 상황에 맞는 소통과 문제 해결 방법을 실천하도록 돕는 과학적 근거 기반 육아 동반자
- 장기 비전: 신뢰할 수 있는 육아 콘텐츠를 중심으로 커뮤니티, 육아 강좌와 육아용품 서비스를 연결하는 육아 통합 플랫폼

## 해결할 문제

- 문제: 부모는 아이의 감정·행동 문제를 마주했을 때 신뢰할 수 있고 지금 바로 실천할 수 있는 대응 방법을 찾기 어렵다.
- 현재 해결 방식: 검색, 온라인 커뮤니티, 지인의 조언과 단편적인 콘텐츠를 오가며 정보의 신뢰성과 적용 가능성을 부모가 직접 판단한다.
- 이 제품이 제공할 핵심 가치: 부모가 어려운 순간에 아이의 연령과 상황에 맞는 근거 기반의 다음 행동을 쉽고 빠르게 확인하도록 돕는다.

## 핵심 사용자

- 주요 사용자: 만 2~7세 아이를 양육하며 감정·행동·소통 문제에 실질적인 도움이 필요한 부모 및 주 양육자
- 보조 사용자 또는 관리자: 콘텐츠를 작성·검토하는 운영자와 향후 참여할 육아·보건 분야 전문가
- 사용 환경: 스마트폰을 우선 지원하는 반응형 웹. 부모가 아이를 돌보는 중에도 짧은 시간 안에 한 손으로 핵심 내용을 확인할 수 있어야 한다.

## 핵심 사용자 흐름

1. 사용자가 현재 겪는 감정·행동 상황을 찾거나 선택한다.
2. 아이의 연령과 구체적인 상황에 맞는 가이드를 확인한다.
3. 지금 할 행동, 피해야 할 행동과 아이에게 건넬 말의 예시를 실천한다.
4. 필요하면 근거 자료, 추가 학습 내용과 전문가 도움이 필요한 신호를 확인한다.

## 첫 버전 범위

### 반드시 포함

- [ ] 모바일 중심의 상황별 감정·행동 가이드 탐색
- [ ] 만 2~7세 연령 범위에 맞는 가이드 구분
- [ ] 각 가이드의 지금 할 행동, 피해야 할 행동과 대화 예시
- [ ] 가이드의 근거 출처, 근거 수준, 검토 여부와 최신 검토일 표시
- [ ] 데이터 없음, 잘못된 접근과 서비스 오류 상태 안내
- [ ] 전문가 또는 긴급 도움을 받아야 하는 범위에 대한 명확한 안전 안내

### 명시적으로 제외

- [ ] 사용자 커뮤니티와 사용자 제작 콘텐츠
- [ ] 육아용품 판매, 추천과 사용자 간 거래
- [ ] 유료 또는 체계적인 육아 강좌
- [ ] AI 또는 서비스에 의한 의료 진단과 개인별 치료 지시
- [ ] 서비스가 독자적으로 판단하거나 생성하는 응급 처치 안내
- [ ] 로그인, 아이 프로필과 개인화 데이터 저장

## 콘텐츠 신뢰성 원칙

- 공공기관 지침, 임상 가이드라인, 체계적 문헌고찰과 동료평가 연구를 우선한다.
- 출처의 종류와 근거 수준을 구분하고 원문을 확인할 수 있게 한다.
- 연구 결과, 편집자의 해석과 실천 제안을 구분한다.
- 전문가 검토 여부와 최신 검토일을 표시한다.
- 근거가 부족하거나 전문가 사이에 의견이 나뉘는 내용은 확정적으로 표현하지 않는다.
- 콘텐츠 변경 이력을 관리하고 정기적인 재검토 절차를 마련한다.

## 안전 원칙

- 서비스는 의료 진단이나 전문 상담을 대체하지 않는다.
- 위험 신호가 있는 상황에서는 일반 육아 가이드보다 지역의 긴급기관과 전문가 연결을 우선한다.
- 응급 관련 콘텐츠는 검증된 공공기관 자료와 자격 있는 전문가의 검토 없이 제공하지 않는다.
- 아동과 보호자의 개인정보는 기능 제공에 반드시 필요한 최소 범위에서만 수집한다.

## 성공 기준

- [ ] 사용자가 대표적인 감정·행동 상황을 선택해 대응 가이드와 근거를 처음부터 끝까지 확인할 수 있다.
- [ ] 모바일 화면에서 사용자가 핵심 대응 행동과 대화 예시를 별도의 설명 없이 찾을 수 있다.
- [ ] 모든 공개 가이드에 출처, 근거 수준, 검토 여부와 최신 검토일이 표시된다.
- [ ] 위험하거나 서비스 범위를 벗어나는 상황에서 전문기관 이용 안내를 확인할 수 있다.
- [ ] 출시 전 사용성 검증 방법과 정량 기준을 별도 작업으로 확정한다.

## 제약과 위험

- 예상 사용자 및 데이터 규모: 초기 검증 단계로 미정. 성능·운영 설계 전에 목표치를 확정한다.
- 개인정보·결제·법적 고려사항: 아동 관련 정보와 건강 관련 입력 가능성을 고려해야 한다. 첫 버전은 계정과 개인화 저장을 제외하며, 공개 전 개인정보·의료 정보 표현·면책 안내를 전문가와 검토한다.
- 비용 한도: 미정
- 외부 서비스 의존성: 초기에는 미정. 출처 링크를 제외한 외부 서비스 도입은 별도 결정으로 기록한다.
- 주요 위험: 부정확하거나 과도하게 일반화된 조언, 오래된 근거, 응급상황 대응 지연, 성별 고정관념 강화와 복잡한 화면으로 인한 사용 실패

## 향후 확장 방향

- 발달과 개인차를 존중하는 남아·여아 이해 콘텐츠
- 부모 감정 조절과 체계적인 문제 해결 프로그램
- 전문가 검토형 육아 강좌
- 안전한 운영 정책을 갖춘 커뮤니티
- 이해상충과 추천 기준을 공개하는 육아용품 플랫폼

향후 기능은 첫 버전의 핵심 흐름과 콘텐츠 신뢰성이 검증된 뒤 별도 작업으로 정의한다.
