# TASK-001 상황별 육아 가이드 탐색 화면

## 목적

만 2~7세 아이의 부모가 현재 겪는 대표적인 감정·행동 상황을 모바일 환경에서 빠르게 찾고, 실천 가능한 대응 방법과 그 근거를 확인할 수 있게 한다.

## 사용자

- 사용자 역할: 로그인하지 않은 부모 또는 주 양육자
- 시작 조건: 모바일 또는 데스크톱 웹에서 서비스 첫 화면에 접근한다.

## 범위

- 포함:
  - 대표 감정·행동 상황 목록
  - 상황 카드의 제목과 짧은 설명
  - 상황 상세 화면 또는 상세 영역
  - 지금 할 행동, 피해야 할 행동과 대화 예시
  - 적용 연령, 근거 출처, 근거 수준, 전문가 검토 여부와 최신 검토일
  - 전문가 도움이 필요한 신호와 서비스 한계 안내
  - 모바일 우선 반응형 화면
  - 로딩, 빈 목록, 찾을 수 없음과 일반 오류 상태
- 제외:
  - 자유 문장 기반 AI 상담과 자동 생성 답변
  - 검색, 필터와 개인별 추천
  - 로그인, 아이 프로필과 사용자 데이터 저장
  - 관리자 콘텐츠 편집 화면
  - 커뮤니티, 강좌와 커머스
  - 의료 진단, 치료 지시와 독자적인 응급 처치 안내

## 사용자 흐름

1. 사용자가 첫 화면에서 대표적인 감정·행동 상황 목록을 확인한다.
2. 현재 상황과 가장 가까운 항목을 선택한다.
3. 상세 내용에서 지금 할 행동, 피해야 할 행동과 대화 예시를 확인한다.
4. 적용 연령과 콘텐츠의 근거 및 검토 정보를 확인한다.
5. 위험 신호에 해당하거나 도움이 더 필요하면 전문가 및 공공기관 이용 안내를 확인한다.

## 완료 조건

- [ ] 지원되는 모바일 화면에서 대표 상황 목록과 각 항목의 제목 및 설명을 확인할 수 있다.
- [ ] 상황을 선택하면 해당 가이드의 행동 지침, 금지 행동과 대화 예시가 표시된다.
- [ ] 각 가이드에 적용 연령, 출처, 근거 수준, 전문가 검토 여부와 최신 검토일이 표시된다.
- [ ] 전문가 도움이 필요한 신호와 서비스가 의료 진단을 대체하지 않는다는 안내가 표시된다.
- [ ] 목록이 비어 있거나 요청한 가이드가 없거나 데이터를 불러오지 못했을 때 서로 구분되는 안내가 표시된다.
- [ ] 잘못된 경로나 식별자로 다른 비공개 데이터 또는 내부 오류 정보가 노출되지 않는다.
- [ ] 이 작업에서는 개인정보를 입력하거나 저장하는 기능이 제공되지 않는다.
- [ ] 핵심 흐름, 빈 상태, 오류 상태와 반응형 화면에 대한 자동 또는 수동 검증 결과가 기록된다.

## 예외 및 경계 상황

- 상황 목록이 비어 있는 경우
- 존재하지 않거나 잘못된 상황 식별자로 접근한 경우
- 콘텐츠 필수 항목 또는 출처 정보가 누락된 경우
- 지나치게 긴 제목, 설명, 출처명이 있는 경우
- 데이터를 불러오는 중이거나 네트워크 요청이 실패한 경우
- 상세 화면을 새로고침하거나 브라우저 뒤로가기를 사용하는 경우
- 상황 카드를 빠르게 중복 선택하는 경우
- 좁은 모바일 화면과 큰 글자 설정을 사용하는 경우

## 데이터·보안 영향

- 추가·변경·삭제되는 데이터: 공개용 가이드 데이터 구조가 추가될 수 있다. 저장 방식은 기술 스택 결정 후 확정한다.
- 개인정보 여부: 없음. 자유 입력과 사용자 식별 정보는 수집하지 않는다.
- 인증 및 권한 조건: 공개 읽기 전용 기능이며 로그인은 필요하지 않다. 향후 비공개 초안이 생기면 서버에서 공개 상태를 확인해야 한다.
- 로그 및 외부 전송 영향: 원문 사용자 입력은 없다. 접근 로그와 분석 도구 도입 여부는 이 작업에서 결정하지 않는다.
- 안전 조건: 예시 콘텐츠도 실제 서비스에 공개할 경우 출처와 적격 전문가의 검토를 받아야 한다. 검토 전 콘텐츠는 데모임을 명확히 표시한다.

## 검증 계획

- 단위 테스트: 가이드 필수 항목, 적용 연령, 출처 및 검토 메타데이터의 유효성 검사
- 통합 테스트: 상황 목록 조회, 상세 조회, 빈 목록, 찾을 수 없음과 데이터 오류 처리
- 사용자 흐름 테스트: 첫 화면에서 대표 상황을 선택하고 행동 지침 및 근거를 확인하는 전체 흐름
- 수동 확인: 지원 화면 크기, 키보드 탐색, 큰 글자, 명확한 로딩·빈 상태·오류 상태와 안전 문구

## 구현 전 확정 사항

- 기술 스택과 지원 브라우저
- 첫 대표 상황과 공개할 실제 콘텐츠
- 근거 수준 분류 체계와 전문가 검토 절차
- 콘텐츠 저장 방식
- 접근성 및 모바일 화면의 구체적인 검수 기준

## 선행 작업

- `TASK-003`에서 공개 web 실행 경계를 만들고 `TASK-002`에서 publication snapshot 및 승인 조건을 확정한다.
- 선행 작업이 완료되지 않으면 검토되지 않은 예시 데이터를 실제 육아 조언처럼 표시하지 않는다.

## 작업 기록

- 상태: 대기
- 결정 사항: 첫 구현은 상황별 감정·행동 가이드 탐색으로 한정한다.
- 미검증 사항: 실제 사용자 조사, 콘텐츠의 전문가 검토, 법률 검토와 정량적 사용성 기준
- 남은 위험: 검토되지 않은 예시가 의학적 조언으로 오해될 가능성, 연령별 발달 차이를 과도하게 일반화할 가능성
