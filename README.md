# Pare

Pare는 부모가 아이의 감정과 행동을 이해하고 상황에 맞는 소통과 문제 해결 방법을 실천하도록 돕는 근거 기반 육아 동반자다.

현재는 제품 및 기술 기준을 확정하는 초기 단계다. 구현 전에 다음 문서를 순서대로 확인한다.

1. `AGENTS.md`
2. `docs/PRODUCT.md`
3. `docs/DEVELOPMENT_RULES.md`
4. 작업 성격에 맞는 `docs/` 기준 문서
5. `tasks/TASK-XXX.md`

## 현재 범위

- 대상: 만 2~7세 아이의 부모 및 주 양육자
- 첫 기능: 모바일 중심 상황별 감정·행동 가이드 탐색
- 핵심 원칙: 승인된 근거만 공개하고, AI는 검토된 지식을 제한적으로 전달한다.
- 제외: 의료 진단, 개인별 치료 지시, 독자적으로 생성한 응급 처치, 커뮤니티, 커머스와 개인화 저장

작업 현황은 `tasks/README.md`, 중요한 결정은 `docs/DECISIONS.md`에서 관리한다.
