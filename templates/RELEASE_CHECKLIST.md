## 배포 전

- [ ] 포함되는 작업과 제외되는 작업을 확인했다.
- [ ] 전체 관련 테스트와 빌드가 통과했다.
- [ ] 비밀정보, 테스트 계정과 가짜 데이터를 확인했다.
- [ ] 마이그레이션과 이전 버전 호환성을 확인했다.
- [ ] 필요한 백업과 실제 복원 가능성을 확인했다.
- [ ] 되돌리기 조건과 절차를 확인했다.
- [ ] 사용자 영향과 공지 필요성을 확인했다.

## 배포 중

- [ ] 배포 시작 및 완료 시간을 기록했다.
- [ ] 배포 및 마이그레이션 로그를 확인했다.
- [ ] 실패 시 추가 변경을 멈추고 복구 판단을 했다.

## 배포 후

- [ ] 서비스 상태와 핵심 사용자 흐름을 확인했다.
- [ ] 오류율, 응답 시간과 자원 사용량을 확인했다.
- [ ] 데이터 정합성과 외부 서비스 연결을 확인했다.
- [ ] 보안·권한 기능을 표본 확인했다.
- [ ] 발견된 문제와 후속 작업을 기록했다.
